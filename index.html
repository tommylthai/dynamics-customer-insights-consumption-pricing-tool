Methodology and agent identity

Calculation method

  • For each included agent: monthly driver × adoption % × activities per driver unit × assumed credits per activity. Journey Creation is driven by new journeys; Outreach Optimization by contacts entering journeys.
  • Fractional journeys, contacts, and activities represent expected averages; no intermediate rounding is applied.
  • The usage subtotal is buffered once, then rounded up once to a whole planning credit.
  • Customer Insights licenses include 0 Copilot Credits, so available capacity is only the credits you allocate. Additional credits never go below zero.
  • The prepaid comparison rounds additional credits up to whole packs. Buffer and pack rounding are budgeting choices, not Microsoft billing rules.

Agent identity and cautions

  • Journey Creation Agent replaces Journey Copilot for journey creation. Count journey-building work once, under Journey Creation Agent.
  • Copilot features such as segment query assist, content ideas, content rewrite, and image recommendations aren't metered: Microsoft's Copilot overview doesn't document Copilot Credit use for them.
  • Out of scope: agents you build in Copilot Studio for conversational journeys, the Customer Insights MCP server, Customer Insights skills in Microsoft 365 Copilot, and Customer Insights - Data. Estimate those separately.
  • Both agents are in preview, so features and metering can change. Use per-agent consumption limits and monitor actual usage in the Power Platform admin center.
  • Included agents with activity but no rate are excluded from numeric totals and make the forecast incomplete.
